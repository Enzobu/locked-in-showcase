# Locked'In

Frontend vitrine pour la solution de casiers connectés modulaires Locked'In.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- next-themes
- composants UI maison inspirés de shadcn/ui

## Lancer le projet
```bash
npm install
npm run dev
```

## Pages
- `/` : Home
- `/solutions` : Gamme de casiers et modularité
- `/platform` : Application mobile + backoffice
- `/contact` : Formulaire de contact front-only
- `/configurator` : Teaser du futur configurateur

## Notes
- Le thème sombre est le thème par défaut.
- Le formulaire de contact n'envoie rien pour l'instant.
- Le configurateur n'est pas encore développé, la page sert de teaser produit.
